# Help & User Guide
> QUICK START & COMPLETE MANUAL

## One-Minute Quick Start
1. Click New Canvas and set the width, height, and DPI. These settings are locked for the project after creation.
2. Under Parametric Shapes on the left, choose a shape, text, or grating and enter its center, dimensions, layout, and rotation. You can also choose Draw from the toolbar.
3. Use the Layers panel on the right to control visibility, locking, and stacking order. A gray-and-white checkerboard indicates transparency.
4. Use a selection to limit painting, copy the final visible result, or move selected content within the current layer.
5. Save a .bmask project to preserve your layers. Set the export file name at the bottom right, then export PNG, CSV, or TXT.

## 1. Canvas, Pixels & Coordinates | Canvas & Coordinates

The origin is the top-left corner of the canvas. X increases to the right and Y increases downward, matching the rows and columns of exported matrices. For a canvas of width W and height H, valid pixel coordinates are X=0–W−1 and Y=0–H−1. The right edge at X=W and bottom edge at Y=H are geometric boundaries, not writable pixels.

Set the width, height, and DPI when creating a canvas. These settings cannot be changed directly afterward, and every layer always matches the canvas dimensions. DPI determines physical dimensions and PNG metadata; it does not change the pixel matrix. The final visible composite is used for inspection and export, and is not edited directly.

All editable numeric fields support basic arithmetic, such as 1920/2, 540+100, or (540+100)/2, using +, -, *, /, decimals, and parentheses. The expression remains visible while you type; press Enter or leave the field to show the result. Parameter limits, linked dimensions, and unit rules still apply. Invalid expressions or division by zero are highlighted in red. Correct them before creating a canvas or applying a shape.

## 2. Parametric Shapes, Text & Gratings | Shapes, Text & Gratings

Circles, triangles, and rectangles use their geometric centroid as both their center and rotation pivot. Shapes are sampled at pixel centers, so the discrete pixel count near an edge may differ slightly from the continuous area. Shapes extending beyond the canvas are clipped automatically; only pixels inside the canvas are written.

Circles use Diameter X and Diameter Y; rectangles use Width X and Height Y. When the link is active, the current X:Y aspect ratio is locked, and changing either dimension updates the other. Triangles use a base length, its corresponding height, and the distance from the left end of the base to the apex's projection on it. Enable Equilateral triangle to calculate the height and projection automatically. Positive rotation is clockwise. Choose px or mm for dimensions. Boolean operations can set 1, set 0, or apply XOR.

Choose Text to enter one or more lines and set the text block's center, font size, font family, weight, line height, letter spacing, alignment, and rotation. Font size and letter spacing use the current px/mm units; the center applies to the whole text block. The preview and applied result use the same layout. Antialiased edges are converted to strictly binary pixels at a 50% coverage threshold, with out-of-bounds areas clipped. Once applied, text becomes ordinary pixels in the current layer rather than an editable text object. Undo to adjust the settings and apply it again.

Text rendering uses fonts available on the device, with fallback families for sans serif, serif, and monospace. Rasterizing the same project on a device without the same fonts may produce slightly different glyphs. Pixels already written to layers and saved in a .bmask file do not change.

Grating generates a one-dimensional, evenly spaced linear grating. Its center is the rectangle's center, rotation pivot, and phase reference. The rectangular boundary and stripes rotate together. At 0°, the lines are vertical and the period runs along X. At phase 0, the center of a reference bright line passes through the grating center. Positive phase moves it along the positive period direction. Phase can be positive or negative and repeats every period. Area width and height can be linked; period, phase, and area dimensions all use the current px/mm units.

The duty cycle is limited to 0%–100%. A pixel is assigned to a grating line according to its center's distance from the nearest reference line center, using half the line width as the threshold and a fixed half-open boundary convention. The result contains no antialiasing or gray values. Periods below 2 px are allowed, but the interface warns about discrete sampling or aliasing.

Full coverage writes opaque 0/1 values throughout the rotated rectangle, using Lines 1 · Gaps 0 or the inverse. Lines only applies Set 1, Set 0, or XOR to line pixels, leaving the gaps' existing transparent/0/1 values unchanged. Gratings ignore the current selection and are clipped only by their rectangle and the canvas. Locked layers cannot be modified. Each application is one undo step. Once applied, a grating becomes ordinary pixels and requires no extra .bmask project format.

## 3. Drawing & Erasing | Drawing & Erasing

Choose Draw or Erase to reveal its size slider. A value bubble appears while you drag it. Beside the Draw slider, choose black 0 or white 1. Erasing always writes transparency, never black. The canvas cursor shows the actual brush diameter, with a center marker for the paint value or eraser state.

When a selection exists, drawing and erasing affect only its area within the current layer. A locked current layer blocks all painting. Transparent, black 0, and white 1 are three distinct internal states.

## 4. Selections, Copying, Pasting & Moving | Selections & Moving

Select creates a rectangular area on the canvas. Ctrl+A selects the entire canvas. Ctrl+D or the × in the selection label clears the selection. Delete/Backspace clears the selected area in the current layer to transparent.

Copy reads the final visible composite within the selection and preserves all three states: transparent, black 0, and white 1. The Paste preview follows the pointer, using its position as the block's top-left corner. It overwrites all three states in the current layer and clips out-of-bounds areas. Arrow keys move the preview by 1 px; Shift+Arrow keys move it by 10 px. Press Enter or double-click the left mouse button to place it and clear the selection. Esc cancels the preview.

Move relocates only the selected transparent/0/1 content in the current layer and clears the source area to transparent. The preview follows the pointer without holding a mouse button, with the pointer marking the content's top-left corner. Arrow keys allow precise adjustment. The floating readout shows the displacement and destination coordinates. Press Enter or double-click the left mouse button to confirm one undo step and clear the selection. Drawing and erasing can then affect the entire layer. Switching to Draw, Erase, or Select during a move also confirms it and clears the selection. Switching tools during a paste cancels the unconfirmed paste. Copying alone keeps the selection; while a manually created selection remains active, drawing and erasing stay within its area in the current layer.

## 5. Layers & Compositing | Layers

Every layer matches the canvas dimensions. The New menu creates a transparent layer, a full-canvas black 0 layer, or a full-canvas white 1 layer. A new layer is inserted above the current layer and becomes current, with creation recorded as one undo step. Layers support selection, visibility, locking, duplication, deletion, renaming, and drag reordering. Use the arrows on the right of each layer to move it up or down, or drag the three horizontal lines between them. The red circled cross between the lock button and drag handle deletes that layer. Duplicate immediately creates a copy. Shift selects a range; Ctrl toggles individual layers. Double-click a layer name to rename it.

The topmost nontransparent pixel determines the final visible result. Merge Selected creates a new layer using priority 1 over 0 over transparent at each pixel. Invert and Clear affect only the current layer. Clear All Layers asks for confirmation and requires all affected layers to be unlocked.

## 6. Matrix Editing | Matrix

Open the editor with the Matrix button in the toolbar. Choose Entire Layer, the default, or Current Selection. Cells cycle through transparent → 0 → 1. You can also press 0 or 1 to set a value, or Delete/Backspace for transparency. Text mode uses · for transparent pixels. The first row corresponds to the top of the canvas or selection.

For Current Selection, the input matrix must exactly match the selection's dimensions and replaces only that area in the current layer. For Entire Layer, the dimensions must match the full canvas. Confirming the edit always creates one undo step.

## 7. Projects, Import & Export | Files & Export

A .bmask file stores canvas dimensions, DPI, every layer's three-state pixels, visibility, locking, and the current layer. Saving clears the unsaved-changes indicator. The app asks for confirmation before opening a project or refreshing when changes are unsaved. Importing PNG, CSV, or TXT creates a new layer aligned to the top-left corner and clips out-of-bounds areas.

Set a custom export file name at the bottom right. PNG exports are strictly 1-bit binary images with DPI metadata. In CSV and TXT, the first row corresponds to the top of the image. Transparent areas are exported as 0. Large saves, exports, merges, and matrix operations show a nonblocking progress message.

## 8. Zoom, Pan & Shortcuts | View & Shortcuts

Use the mouse wheel to zoom around the pointer, or enter a percentage at the right of the toolbar. At 100%, one image pixel corresponds to one screen pixel. Fit to Window calculates and displays the zoom percentage. Ctrl+0 fits the canvas to the window; Ctrl+1 returns to 100%. Hold Space while dragging, or drag with the middle mouse button, to pan without adding an undo step.

Ctrl+Z | Undo
Ctrl+Shift+Z / Ctrl+Y | Redo
Ctrl+S / Ctrl+O | Save / Open project
B / E | Draw / Erase
M / V | Select / Move
[ / ] | Decrease / Increase brush size
Ctrl+C / Ctrl+V | Copy / Paste selection matrix
Arrow keys / Shift+Arrow keys | Move 1 px / 10 px

Letter shortcuts are disabled while typing in input fields, dropdowns, the text matrix editor, or dialogs. Shortcuts cannot bypass a layer's lock.
